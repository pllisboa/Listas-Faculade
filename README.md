<h1>Listas-Faculade</h1>

<p> Repositório criado para organizar e compartilhar as resoluções das listas de exercícios da faculdade. Atualmente, o projeto conta com exercícios básicos desenvolvidos em C# e algumas soluções em Java. O objetivo é documentar o aprendizado, praticar lógica de programação e servir como fonte de consulta ao longo do curso. </p>
